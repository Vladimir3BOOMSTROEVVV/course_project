# Курсовой проект
## Реализация программы контроля облачной инфраструктуры

### Этап 1

#### 1. Назначение программы.
Программа на языке C предназначена для анализа работы облачной инфраструктуры по последовательности телеметрических измерений. Она получает показатели компонентов за несколько отсчётов, рассчитывает производные показатели и определяет состояние компонентов по заданному правилу.

#### 2. Описание индивидуального варианта.
Вариант №8

Компоненты: **QUE, TLS, DNS**.

Порядок записи: **Б — значение — время — компонент**. Разделитель: **запятая**.

Тип последовательности (5): есть записи с неизвестными кодами компонентов; их нужно распознать и пропустить.

Телеметрия за пять отсчётов — одна строка:

```text
35.2,4,DNS,53.8,1,TLS,30.6,3,DNS,44.2,2,QUE,31.3,2,DNS,50.6,4,QUE,51.1,5,QUE,51.2,5,TLS,34.5,5,DNS,43.7,1,QUE,44.7,3,QUE,57.2,2,TLS,32.0,1,DNS,73.0,2,XYZ,55.2,3,TLS,76.0,5,XYZ,53.2,4,TLS
```

Производный показатель **Q: темп роста**.

Формула:

$$
Q[i] = \frac{X[i]}{X[i-k]}, \qquad k = 2,\quad L = 0.8,\quad D = 5
$$

Правило состояния компонента — **превышение порога**: если $|Q| > L$, состояние «ТРЕВОГА», иначе «НОРМА».

Правило инцидента — **ровно один проблемный**: инцидент возникает, если ровно один компонент проблемный, а два других находятся в состоянии «НОРМА».

Структура Incident:

```
typedef struct {
    int time;
    int type;
    int count;
    float value;
} Incident;
```
Поля: номер отсчёта, тип, число проблемных компонентов, значение показателя.

**Вручную рассчитал производные показатели для пяти значений**

Для первого этапа используем отношение текущего значения к предыдущему, $Q[i]=X[i]/X[i-1]$:

```text
QUE
Q[1] = 44.2 / 43.7 = 1.0114
Q[2] = 44.7 / 44.2 = 1.0113
Q[3] = 50.6 / 44.7 = 1.1320
Q[4] = 51.1 / 50.6 = 1.0099

TLS
Q[1] = 57.2 / 53.8 = 1.0632
Q[2] = 55.2 / 57.2 = 0.9650
Q[3] = 53.2 / 55.2 = 0.9638
Q[4] = 51.2 / 53.2 = 0.9624

DNS
Q[1] = 31.3 / 32.0 = 0.9781
Q[2] = 30.6 / 31.3 = 0.9776
Q[3] = 35.2 / 30.6 = 1.1503
Q[4] = 34.5 / 35.2 = 0.9801
```

**Вручную определил ожидаемый результат исходя из правила контроля**

Порог $L=0.8$. Для состояния «ТРЕВОГА» должно выполняться $|Q|>0.8$.

- QUE: $1.0114;\ 1.0113;\ 1.1320;\ 1.0099$ — все четыре показателя в состоянии «ТРЕВОГА».
- TLS: $1.0632;\ 0.9650;\ 0.9638;\ 0.9624$ — все четыре показателя в состоянии «ТРЕВОГА».
- DNS: $0.9781;\ 0.9776;\ 1.1503;\ 0.9801$ — все четыре показателя в состоянии «ТРЕВОГА».
